確率の基礎

ランダムに起こることを数で扱うための最小限の用語です。

確率

probabilityP(A)

ある事象が起こることの起こりやすさを、0以上1以下の数で表したもの。0は「決して起こらない」、1は「必ず起こる」を表す。事象とは「偶数の目が出る」のような、試行の結果として起こりうる出来事のこと。

例公正なサイコロで1の目が出る確率は 1/6。

補足同じ試行を繰り返すと、その事象が起こった割合(相対度数)は繰り返しが増えるほど確率に近づく。この性質が大数の法則(01)。確率は「次の1回の結果を当てる」ものではなく、「長い目で見た割合」を表す。

確率変数

random variableXx

試行の結果によって値が決まる変数。試行の前は値が定まっておらず、試行の後に1つの値(実現値)が決まる。

表記確率変数は大文字 X、実際に得られた値(実現値)は小文字 x で書く。

例サイコロを1回振って出る目を X とする。実際に3が出たなら x = 3。

確率分布

probability distribution

確率変数がどの値をどれくらいの確率でとるかを表したもの。すべての確率の合計(連続なら曲線の下の面積)は1になる。

とびとびの値をとる場合(サイコロなど)は、各値の確率を並べる。連続した値をとる場合(体重や濃度など)は密度の曲線で表し、ある区間の確率は、その区間で曲線の下にできる面積になる。

例サイコロは「1〜6の目がそれぞれ 1/6」。02 中心極限定理で使う一様分布・指数分布・二峰性分布もすべて確率分布。

母集団と標本

「知りたい全体」と「実際に手元にある一部」を区別するのが、統計の出発点です。

母集団

population

知りたい対象の全体。

例「ある地域の全成人の血圧」「このワイナリーで将来醸造されうるすべてのバッチの品質」。現実には全体を調べられないことが多く、「同じ試行を無限に繰り返せるとしたときの結果」を母集団とみなすこともある。

この教材のシミュレーションでは、母集団をサイコロや一様分布などの確率分布として与え、そこから乱数で標本を取り出している。

母数

parameterμσ²

母集団の特徴を表す定数。母平均 μ、母分散 σ²、母標準偏差 σ など。

現実の研究では母数は未知で、標本から推測する対象になる。母数はギリシャ文字、標本から計算する値はラテン文字で書く慣習がある。

補足シミュレーションでは私たちが母集団を設定するので、母数の真の値がわかる。推定の良し悪しを確かめられるのは、そのため。

標本

samplex1, …, xn

母集団から取り出した観測値の集まり。

標本から母集団の性質を推測することを統計的推測という。標本が母集団を代表するには、取り出し方に偏りがないことが必要で、そのための方法が無作為抽出。

無作為抽出

random sampling

母集団のどの要素も等しい確率で選ばれるように、でたらめに取り出すこと。取り出す側の都合や好みが入らないようにして、標本の偏りを避ける。

注意「無作為抽出」(母集団から標本を選ぶ)と「無作為割り付け」(集めた対象を処理群や実験順序に振り分ける)は別の操作。04・05のランダム化は後者。

独立同分布

i.i.d.

標本の各観測値が、(1)互いに独立で(ある値が他の値に影響しない)、(2)同じ確率分布に従うこと。independent and identically distributed の頭文字。

この教材のシミュレーションで作る標本は、すべてこの前提(同じ分布から、毎回独立に引く)を満たしている。標準誤差の公式 σ/√n も、この前提のもとで成り立つ。

標本サイズ

sample sizen

1つの標本に含まれる観測値の個数。「サンプルサイズ」ともいう。

例12人の血圧を測ったなら n = 12。02の n スライダー、03の各群の n がこれにあたる。

補足n を増やすと、標本平均のばらつき(標準誤差)は小さくなる。

標本数

number of samplesr

標本を取った回数(標本の個数)。

例n = 5 の標本を2000回取ったなら、標本サイズは 5、標本数は 2000。02の「繰り返し回数 r」がこれ。

注意標本数は標本サイズ n とはまったく別のもの。文献によっては「標本数」を標本サイズの意味で使うことがあるため、この教材では「標本サイズ = 観測値の個数」「標本数 = 標本を取った回数」と使い分ける。

現実の研究では、標本は通常1つだけ(標本数 = 1)。標本を何度も取り直すのは、シミュレーションや理論上の思考実験。

分布の平均とばらつき

母集団(確率分布)の側の量です。分布が決まれば値も決まる定数で、標本から計算する量とは区別します。

期待値・母平均

expected value / population meanE[X]μ

確率分布の「平均」。同じ試行を非常に多く繰り返したときの平均が近づく値。確率変数 X の期待値を E[X]、母集団の平均を母平均 μ と書く。

E[X] = Σ x · P(X = x)　(とびとびの値の場合)

例サイコロなら (1+2+3+4+5+6)/6 = 3.5。01のオレンジの破線が μ。

注意母平均は分布が決める定数。標本から計算する標本平均とは別のもの。

偏差

deviation

観測値と平均との差。標本なら xi − x、母集団なら X − μ。

偏差をそのまま足すと正負が打ち消し合って、標本では必ず 0 になる。そのため、ばらつきを測るには偏差を二乗して使う(→分散)。

分散

varianceVar(X)σ²

ばらつきの大きさを表す指標。偏差を二乗した値の期待値。母集団の分散を母分散 σ² と書く。

σ² = E[(X − μ)²]

例サイコロの分散は 35/12 ≈ 2.92。

補足単位が元の値の2乗になる(mg なら mg²)。そのままでは解釈しにくいので、平方根をとった標準偏差がよく使われる。

標準偏差

standard deviationσSD

分散の平方根。元の値と同じ単位で、個々の観測値が平均からどれくらい離れているかの典型的な大きさを表す。

σ = √σ²

例サイコロの標準偏差は √2.92 ≈ 1.71。

注意ここで扱うのは母集団の標準偏差 σ。標本から計算するものは標本標準偏差 s と呼んで区別する。また、平均のばらつきを表す標準誤差とは別のもの。

標本から計算する量

標本を取るたびに値が変わる量です。母数を推測するための材料になります。

統計量

statistic

標本から計算される値。標本平均、標本分散、中央値、t値など。

注意標本が変わると統計量の値も変わる(確率変数)。一方、母数は標本が変わっても動かない定数。「変わる量」と「変わらない量」の区別が、以降の用語を理解する軸になる。

標本平均

sample meanx

標本の観測値の合計を、標本サイズで割った値。母平均 μ の推定に使う。

x = (x1 + x2 + … + xn) / n

標本を取り直すたびに値が変わる。その変わり方の分布が標本分布。

標本分散

sample variance (÷n)S²

標本の観測値が標本平均からどれくらい散らばっているかを、偏差の二乗の平均で表した値。標本そのもののばらつきを記述する。

S² = { (x1 − x)² + (x2 − x)² + … + (xn − x)² } / n

注意母分散 σ² の推定値として使うと、平均的に小さめになる(→不偏性)。標本平均 x は標本の値に合わせて決まるので、μ からの偏差の二乗和より x からの偏差の二乗和の方が必ず小さくなるため。

注意教科書によっては、n−1 で割る方を「標本分散」と呼ぶ。この教材では、n で割るものを「標本分散」、n−1 で割るものを「不偏分散」と呼び分ける。記号も本によって違うので、式の分母を必ず確認する。

不偏分散

unbiased variance (÷n−1)s²u²

母分散 σ² を推定するために、偏差の二乗和を n ではなく n−1 で割った値。期待値が σ² と一致する(不偏性をもつ)。

s² = { (x1 − x)² + (x2 − x)² + … + (xn − x)² } / (n − 1)

実務Excel の VAR.S、R の var()、pandas の .var() は n−1 で割る(不偏分散)。Excel の VAR.P は n で割り、NumPy の np.var() は既定で n で割る(ddof=1 を指定すると n−1)。

補足n = 1 のときは n−1 = 0 で計算できない。観測値が1個ではばらつきを推定できない、ということでもある。

自由度

degrees of freedomdf

標本の中で自由に値を決められる、独立な情報の数。

偏差 xi − x をすべて足すと必ず 0。したがって、n個のうち n−1個が決まると最後の1個は自動的に決まる。偏差についての自由度は n−1 で、不偏分散の分母の n−1 はこの自由度。

03 t検定で使う t 分布の自由度も、標本サイズから決まる同じ種類の量。

標本標準偏差

sample standard deviations

不偏分散の平方根。元の単位で標本のばらつきを表し、母標準偏差 σ の推定値として使う。

s = √s²

注意不偏分散 s² は σ² の不偏推定量だが、その平方根 s は σ の不偏推定量ではない。s は平均的に σ よりわずかに小さくなる(n が大きいほど差は小さい)。下の体験で確かめられる。

ばらつきと推定

標本を取り直したときの統計量のふるまいと、推定量の良し悪しを表す用語です。

標本分布

sampling distribution

統計量が、標本ごとにとる値の確率分布。同じ母集団から標本を何度も取り直すと、標本平均 x は毎回違う値になる。その x の分布が「標本平均の標本分布」。

例02の下段のヒストグラムがこれ。標本平均の標本分布の中心は母平均 μ、ばらつきの大きさが標準誤差。

注意「標本の分布」(1つの標本の中で観測値がどう散らばっているか)とは別のもの。標本分布は、標本を取り直したときの統計量の分布。

標準誤差

standard errorSE

統計量の標本分布の標準偏差。その統計量が、標本ごとにどれくらいばらつくか(推定の精度)を表す。標本平均の標準誤差は次の式になる。

SE(x) = σ / √n　　σ が未知のときは s で置き換えて　SE ≈ s / √n

例σ = 10 のとき、n = 25 なら SE = 2、n = 100 なら SE = 1。n を4倍にすると SE は半分になる。

注意標準偏差は「観測値のばらつき」で、n を増やしても(母集団の σ は)変わらない。標準誤差は「平均のばらつき」で、n を増やすと √n に反比例して小さくなる。02の「理論 SE」と「実測 SD(標本平均)」は、この2つを比べている。

推定量・推定値

estimator / estimateθ̂

母数 θ を推測するために標本から計算する統計量(計算方法)を推定量、実際のデータで計算した具体的な数値を推定値という。母数の記号にハット(^)を付けて θ̂ と書く。

例母平均 μ の推定量は標本平均 x。12人のデータから計算した x = 126.8 mmHg が推定値。

推定量は標本ごとに変わる確率変数、推定値はそのうちの1つの実現値。

バイアス

bias

推定量の期待値と、真の母数との差。0でないとき「偏りがある」という。

バイアス = E[θ̂] − θ

例n で割る標本分散 S² のバイアスは −σ²/n(平均的に σ²/n だけ小さい)。

不偏性

unbiasedness

推定量の期待値が、真の母数に一致すること。バイアスが 0 であること。「標本を取り直して何度も推定したとき、その平均が真の値に一致する」ということ。

E[θ̂] = θ

例標本平均 x は μ の不偏推定量(E[x] = μ)。不偏分散 s² は σ² の不偏推定量(E[s²] = σ²)。n で割る標本分散 S² は不偏ではなく、E[S²] = (n−1)/n × σ²。

注意不偏性は「平均的に当たる」ことであり、1回の推定値が真の値に近いことの保証ではない。1回ごとの近さは標準誤差(ばらつきの小ささ)で決まる。

一致性

consistency

標本サイズ n を大きくすると、推定量が真の母数に近づいていくこと。

例標本平均 x は n が大きくなると μ に近づく。これが大数の法則(01)。

補足不偏性は「平均的に当たる」、一致性は「n が大きいと当たる」という別の性質。n で割る標本分散 S² は不偏ではないが、バイアス σ²/n は n とともに小さくなるので一致性はある。

体験:不偏性と標準誤差を確かめる

母集団を正規分布 N(母平均 μ = 50, 母標準偏差 σ = 10)、つまり母分散 σ² = 100 として、標本サイズ n の標本を r 回取ります。各標本から x、S²、s²、s を計算し、r 個の平均を真の値と比べます。

統計量実測(r 個から集計)理論上の平均比べる真の値実測 ÷ 真の値

棒の長さは「実測 ÷ 真の値」(右端は 1.20)。縦線が 1.00(真の値と一致)。オレンジの棒は偏りのある統計量。

各行の計算(現在の n と r で計算)

標本を r 回取り、標本 k(k = 1〜r)ごとに、標本平均 xk = (x1 + … + xn) / n と、偏差の二乗和 SSk = (x1 − xk)² + … + (xn − xk)² を求めます。上の表の「実測」は、これを r 個分まとめた値です。「実測 ÷ 真の値」は実測を真の値で割った比で、1.00 なら一致を表します。

統計量実測の計算比べる真の値理論上の平均と、理論上の比
  • n で割る標本分散 S² は、真の値より小さくなる。比は (n−1)/n に近づく(n = 5 なら 0.80)。n−1 で割る不偏分散 s² は 1.00 付近になる。
  • s は s² の平方根だが、1.00 より少し小さい。不偏分散が不偏でも、その平方根は不偏にならない。
  • 標本平均の標準偏差(標準誤差)は σ/√n に一致する。n を 4 倍にすると半分になる。
  • r を 100 にすると実測値が揺れる。不偏性は「r を十分大きくしたとき平均が近づく」ことを意味している。
