# ハンズオン：占いbotで学ぶCLAUDE.md

## 目的

同じコードへの同じ依頼でも、CLAUDE.mdの有無で結果が大きく変わることを体験する。

---

## Step 1：まずそのまま動かしてみる

```bash
python fortune.py
```

---

## Step 2：CLAUDE.mdなしで改善を依頼する

Claude Codeを起動し、以下のプロンプトをそのまま送ってみてください。

```
fortune.pyをもっと面白くしてください。
```

どんな出力になりましたか？メモしておいてください。

---

## Step 3：CLAUDE.mdを書く

あなたが作りたい占いbotのコンセプトを自由に決めて、CLAUDE.mdに書いてください。

ヒント：以下の要素を盛り込むと効果的です。

- このbotは何のためのもの？（例：学園祭出し物 / 職場の朝礼 / 子ども向けアプリ）
- キャラクターや口調は？（例：ミステリアスな占い師 / 明るいアイドル / 謎の老人）
- どんな運勢カテゴリを扱う？（例：恋愛・仕事・健康 / 今日のラッキーフード）
- 使う言語や絵文字のルールは？

```markdown
# CLAUDE.md
（ここに自由に書く）
```

---

## Step 4：同じ依頼を再実行する

```
fortune.pyをもっと面白くしてください。
```

Step 2の結果と比べてみましょう。何が変わりましたか？

---

## ふりかえり

- CLAUDE.mdがない場合、Claudeは何を根拠に判断したと思いますか？
- CLAUDE.mdを書くことは、誰に向けた説明だと思いますか？
- README.mdとCLAUDE.mdの役割の違いは何でしょう？
